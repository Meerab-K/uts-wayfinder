# UTS-Wayfinder: An AI-based Campus Route Planner
By Dofemina

UTS Wayfinder is a platform aimed to help users find the best path from their starting point to their destination in UTS Broadway.

The platform uses the AI algorithm, A* Search Algorithm, to find the optimal path.

# Features
Through the UTS Wayfinder page, users can select their starting point and destination from the provided locations to find their way around UTS Broadway.
